# Карусель — бесшовные коллажи (PWA)

Мини-приложение для телефона: широкий холст на несколько слайдов, фото кладутся через стыки, экспорт режет всё на отдельные кадры для карусели Instagram.

## Возможности
- Формат слайда: 4:5, 1:1, 3:4, 9:16 (ширина 1080 px)
- От 1 до 20 слайдов
- Фото: перетаскивание одним пальцем, щипок — размер и поворот (поворот прилипает к 0°/90°)
- Обрезка: «Обрезать» → тяни края рамки, чтобы фото влезло в узкое место; фото можно двигать внутри рамки, «Сбросить» вернёт исходник
- Кнопки для выбранного фото: «Слайд» (заполнить слайд), «2 слайда» (растянуть через стык), «Отразить», «Вперёд»/«Назад», «Копия», «Удалить»
- Магнит (кнопка-магнит вверху): края фото прилипают к соседним фото, стыкам слайдов и верху/низу холста — без зазоров и вылетов; в момент прилипания — голубая направляющая и вибрация (Android; на iPhone — iOS 18+)
- Видео: можно вставлять вместе с фото; слайды с видео сохраняются в MP4 (1080 px, без звука, до 60 с)
- Экспорт «Оригинал» (по умолчанию): PNG без сжатия в разрешении исходных фото (до ~3100×3900 для 4:5); режим «1080 · JPEG» — лёгкие файлы для Instagram
- Отмена/повтор (⌘Z / ⇧⌘Z на компьютере), кнопка «Новый проект»
- Автосохранение: проект хранится в браузере и открывается после перезапуска
- Шаблоны: раскладки без пробелов под число фото и слайдов (фото идут через стыки), отступы «Встык / Тонко / Рамка», «Другие варианты»
- «Заполнить пробел»: фото растягивается до соседей и краёв; «Поменять»: два фото меняются рамками
- Цвет фона
- Щипок по пустому месту — масштаб холста, свайп — прокрутка
- Экспорт: отдельный файл на каждый слайд. Кнопка «Сохранить все» открывает меню «Поделиться» в iOS, где есть пункт «Сохранить изображения». Одно фото можно сохранить нажатием на превью.

## Как запустить на телефоне
Приложению нужен HTTPS: без него не работают офлайн-режим и установка на экран «Домой». Достаточно любого статического хостинга:
- **Netlify Drop**: перетащи папку `carousel-app` на https://app.netlify.com/drop
- **GitHub Pages**: залей файлы папки в репозиторий и включи Pages

Затем открой ссылку в Safari и выбери «Поделиться» → «На экран Домой».

Чтобы проверить на компьютере:
```bash
cd carousel-app && python3 -m http.server 8123
```
После этого открой http://localhost:8123.

## Файлы
- `index.html`, `style.css`, `app.js`: само приложение, без зависимостей
- `manifest.webmanifest`, `sw.js`, `icons/`: файлы для установки и работы офлайн
